# work-progress 轻量实验

目标：让用户直接看懂 AI 工作的进度、成果、阻塞与下一步。逐步增加真实需要的能力，定期删减。

范围：本会话的 work-progress Skill 开发、展示与试用；不是 Taskboard 数据库中全部项目或议题的副本。婚礼与 P2P 原型中的模拟任务不作为真实进展导入。

任务事实源：[tasks.yaml](tasks.yaml)。设计与使用说明：[工作进展](../docs/work-progress.md)。维护规则：[Skill](../skills/work-progress/SKILL.md)。

当前使用 Codex visualize 呈现，文件保存事实，Git 保存已提交的历史。未来有实际需要再接入其他展示工具。
